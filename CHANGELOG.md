## Información general

Todos los cambios notables en este proyecto serán documentados de forma detallada en este archivo.

El formato de este registro está basado en [Keep a Changelog](https://keepachangelog.com/es/1.1.0/) y este proyecto adhiere a [Versionado Semántico](https://semver.org/lang/es/) (`MAJOR.MINOR.PATCH`).

### Tipos de cambios

- **Añadido:** para nuevas características o funcionalidades.
- **Cambiado:** para cambios en funcionalidades existentes.
- **Obsoleto:** para características que se eliminarán en próximas versiones.
- **Eliminado:** para características eliminadas en esta versión.
- **Corregido:** para cualquier solución de errores (bug fixes).
- **Seguridad:** en caso de vulnerabilidades o parches de seguridad.
